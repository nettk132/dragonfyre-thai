# dragonfyre-thai

รีซอร์สแพ็กแปลภาษาไทยสำหรับม็อดแพ็ก **Dragonfyre** (Minecraft 1.20.1, `pack_format` 15)

## แพ็กนี้ทำอะไรบ้าง

- **แปลข้อความเป็นภาษาไทย** ครอบคลุมม็อด 231 ตัวในแพ็ก เช่น Ice and Fire, Iron's Spells 'n Spellbooks, Apotheosis, Ars Nouveau, Alex's Mobs, Cataclysm, Farmer's Delight, FTB Quests, Quark, Twilight Forest, Waystones, JEI/EMI ฯลฯ รวมถึง Minecraft เอง
  - แปลเฉพาะข้อความที่ม็อดยังไม่มี `th_th` ของตัวเอง (ของเดิมที่มีอยู่แล้วจะไม่ถูกทับ)
  - **ชื่อไอเทมและบล็อก (`item.*`, `block.*`) คงเป็นภาษาอังกฤษ** เพื่อให้ค้นใน JEI/EMI และเทียบกับวิกิได้ง่าย (กำหนดใน `namekey.txt`)
  - รักษาโค้ดจัดรูปแบบไว้ครบ (`%s`, `%d`, `%1$s`, `§` สีข้อความ, `{...}`, `$(...)` ของ Patchouli, ขึ้นบรรทัดใหม่)
- **แก้ฟอนต์ภาษาไทย** ใช้ฟอนต์ Noto Sans Thai (สัญญาอนุญาต OFL, อยู่ใน `font/`)
  - แก้ปัญหาสระ/วรรณยุกต์ลอยหรือซ้อนผิดตำแหน่ง (ปรับ left side bearing ของฟอนต์)
  - บังคับให้ฟอนต์ไทยมาก่อน unifont ทั้งใน `default`, `include/unifont` และ `uniform` จึงใช้ได้แม้เปิด Force Unicode หรือมีรีซอร์สแพ็กอื่นทับ `default.json`
  - ปรับขนาด (ค่าเริ่มต้น 11) และระยะเลื่อนแนวตั้ง (0.8) ให้เข้ากับฟอนต์ Minecraft

## วิธีติดตั้ง

1. สร้างไฟล์แพ็ก (ดูด้านล่าง) จะได้ไฟล์ `.zip`
2. วางไว้ในโฟลเดอร์ `resourcepacks` ของม็อดแพ็ก
3. ในเกมเปิด *Options → Resource Packs* เปิดใช้แพ็ก แล้วเปลี่ยนภาษาเป็น **ภาษาไทย**

## สร้างแพ็กเอง

ต้องใช้ Python 3

```sh
python build.py . dragonfyre-thai.zip           # ค่าเริ่มต้น
python build.py . dragonfyre-thai.zip 12 1.0    # กำหนดขนาดฟอนต์ / ระยะเลื่อนเอง
```

## โครงสร้างและสคริปต์

| ไฟล์/โฟลเดอร์ | หน้าที่ |
|---|---|
| `extract.py <modpack> <out>` | ดึงข้อความ `en_us` จากทุก `.jar` ใน `mods/` ที่ยังไม่มี `th_th` → `work/<ม็อด>.json` |
| `chunk.py .` | รวมข้อความไม่ซ้ำกันจาก `work/` แล้วแบ่งเป็นชุดละ ~6000 ตัวอักษร → `chunks/` |
| `t/` | คำแปลภาษาไทย เรียงตรงกับ `chunks/` ทีละบรรทัด |
| `check.py . <id...>` | ตรวจว่าคำแปลมีจำนวนบรรทัดและโค้ดจัดรูปแบบตรงกับต้นฉบับ |
| `align.py . <id>` | หาบรรทัดแรกที่คำแปลเริ่มเลื่อน/ไม่ตรงกับต้นฉบับ |
| `nx.sh <id> <next>` | ตรวจชุดที่แปลเสร็จแล้วแสดงชุดถัดไป |
| `findtext.py <modpack> "<ข้อความ>"` | ค้นหาว่าข้อความอังกฤษที่ยังไม่ถูกแปลอยู่ในไฟล์ไหน (เช่น config, quest, KubeJS) |
| `build.py . <out.zip>` | รวมทุกอย่างเป็นรีซอร์สแพ็ก |
